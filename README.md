# Rielle's Bubble Learn 🫧

A bubbly learning app for Rielle: math, grammar, spelling, patterns, memory match and a sticker book.

## Run it
- Double-click `index.html` to open it in your browser, or
- in the VS Code terminal, run `npx serve .` and open the address it prints.

## Work on it with Claude Code
Open this folder in VS Code and start Claude Code. It reads `CLAUDE.md` automatically.
To build the Android app, ask: "Do Phase 1 of the Android plan in CLAUDE.md."
